# دليل مدينة حمص الخدمي والتجاري

دليل إلكتروني تشاركي لحمص — يعمل بالكامل على المتصفح بدون خادم.

## الملفات

| الملف | الوظيفة |
|-------|---------|
| `index.html` | الصفحة الرئيسية (الدليل) |
| `login.html` | تسجيل الدخول / إنشاء حساب |
| `admin.html` | لوحة تحكم المدير |
| `js/auth.js` | نظام المصادقة |
| `js/logger.js` | سجل النشاط |

## النشر على GitHub Pages

1. ارفع جميع الملفات إلى مستودع GitHub
2. فعّل **Settings → Pages → Branch: main**
3. الرابط: `https://username.github.io/repo-name/`

## كيف تعمل البيانات؟

- البيانات تُعرض **فوراً** من المتصفح (localStorage) بدون أي انتظار
- الجهات التي تُضيفها تُحفظ على جهازك أولاً ثم تُرسل للخادم المشترك
- إذا فشل الاتصال، تظهر بياناتك المحلية مباشرةً دون أي توقف
- شاشة Skeleton لا تُرى إلا لأجزاء من الثانية ثم تختفي
