# دليل مدينة حمص الخدمي والتجاري

منصة تشاركية مفتوحة لتسجيل الأطباء، المحامين، الصيدليات، والمحلات في مدينة حمص.

## المميزات

- 📋 **دليل شامل** — بطاقات منظّمة بالأقسام والتخصصات
- 🗺️ **خرائط تفاعلية** — تحديد المواقع بـ Leaflet / OpenStreetMap
- ⭐ **نظام تقييم** — تقييم بالنجوم مع متوسط المجتمع
- 🔐 **لوحة مشرفين** — تسجيل دخول آمن للإضافة والتعديل والحذف
- 🌙 **وضع ليلي** — تصميم متكيف مع المظهر المفضل
- 📱 **متجاوب** — يعمل على الجوال والحاسوب
- 🔗 **Sheetson API** — البيانات محفوظة في Google Sheets

## الإعداد السريع

### 1. إعداد Google Sheets

تأكد أن جدول البيانات يحتوي على هذه الأعمدة في الصف الأول:

| معرف  id | اسم المكان | القسم | الوصف | العنوان بالتفصيل | الخريطة | الهاتف / الجوال | اوقات الدوام  | رابط الفيسبوك / انستغرام | التقييم | الحالة | عدد_التقييمات |
|----------|----------|-------|-------|----------|--------|----------|-----------|----------|---------|-------|------------|

### 2. إعداد Sheetson API

في ملف `index.html`، غيّر هذه المتغيرات في بداية الكود JavaScript:

```javascript
const API_KEY        = 'مفتاحك_هنا';
const SPREADSHEET_ID = 'معرف_الجدول_هنا';
const SHEET_NAME     = 'Sheet1';
```

### 3. رفع على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub
2. ارفع ملف `index.html` مباشرةً
3. فعّل **GitHub Pages** من الإعدادات → Pages → `main branch / root`
4. سيكون الموقع متاحاً على: `https://اسم_المستخدم.github.io/اسم_المستودع/`
