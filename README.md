# دليل مدينة حمص الخدمي والتجاري

دليل إلكتروني تشاركي لحمص يتيح للزوار تصفح المنشآت والخدمات، وتسجيل الدخول للإضافة والتعديل.

## الملفات

| الملف | الوظيفة |
|-------|---------|
| `index.html` | الصفحة الرئيسية — الدليل الكامل (عام) |
| `login.html` | تسجيل الدخول / إنشاء حساب |
| `admin.html` | لوحة تحكم المدير (تتطلب صلاحية مدير) |
| `js/auth.js` | نظام المصادقة والجلسات |
| `js/logger.js` | تسجيل النشاط |

## الاستخدام

### على GitHub Pages
1. ارفع جميع الملفات كما هي إلى مستودع GitHub
2. فعّل **Pages** من `Settings → Pages → Branch: main`
3. سيكون الرابط: `https://username.github.io/repo-name/`

### محلياً
افتح `index.html` عبر خادم محلي (مثل `Live Server` في VS Code)

> ملاحظة: لا يعمل مباشرةً بفتح الملف بدون خادم بسبب `crypto.subtle` الذي يحتاج HTTPS أو localhost
